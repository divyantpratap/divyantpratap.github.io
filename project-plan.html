Credit-card fraud risk lab

A production-style fraud investigation app: PyCaret as the AutoML baseline, then leakage-safe resampling, calibrated risk, cost-aware thresholds, and SHAP explanations.

Build

  1. Validate and split the 284,807-transaction dataset.
  2. Compare naive, logistic, PyCaret, and tree-model baselines.
  3. Keep resampling inside training folds.
  4. Calibrate probabilities and tune the review threshold.
  5. Build the Streamlit investigation queue and explanations.

Evidence that will ship

  • PR-AUC, recall, precision, false positives per 1,000, and expected cost.
  • Threshold trade-off and stability slices.
  • Tests, Docker, CI, model card, screenshots, repository, and live demo.

Definition of done: the app runs from a clean checkout, evaluation is reproducible, and the resume uses verified PR-AUC/recall/cost metrics instead of a misleading accuracy headline.

Flight-fare intelligence

A fare estimator and scenario explorer on 300K+ records, with temporal validation, route-aware feature engineering, Auto-Sklearn comparison, error slicing, and prediction ranges.

Build

  1. Create a leakage-safe time split and route/airline baselines.
  2. Engineer booking horizon, timing, route, stops, class, and duration.
  3. Compare Auto-Sklearn with a strong transparent baseline.
  4. Add interval estimates and segment-level error analysis.
  5. Build the Streamlit quote and scenario-explorer interface.

Evidence that will ship

  • MAE, median AE, RMSE, MAPE/wMAPE, and interval coverage.
  • Error slices by route, airline, class, stops, and booking horizon.
  • Tests, Docker, CI, model card, screenshots, repository, and live demo.

Definition of done: MAE below INR 2,500 is retained on the resume only if the untouched test-set evaluation reproduces it.
